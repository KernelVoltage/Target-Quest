# Target Quest 🎯🏹

**Target Quest** is a 2D physics-based arcade archery puzzle game built with **Godot Engine 4.3**. It combines tactical angle calculations, flat vector art aesthetics, and smooth infinite procedural progression.

---

## ✨ Key Features

* **True Infinite Procedural Generation:** Features hand-crafted onboarding levels (1–4) followed by a smart, unique-seeded procedural level generator from Level 5 onwards to ensure zero level repetition.
* **Collapse-Free Grid Distribution:** Uses a strict safe-distance spatial partition algorithm that prevents targets and bases from overlapping or collapsing into each other.
* **Dynamic Moving Platforms:** Progressive difficulty scaling where select wooden bases begin smooth, jerk-free vertical and horizontal sine-wave movements starting at Level 10.
* **Immersive Arrow Embedding & Z-Indexing:** Arrows dynamically reparent to hit targets (eggs, wooden bases, or ground) while preserving global transforms and adjusting `z-index` depth stacking for a realistic embedded look.
* **Audio Feedback Integration:** Custom sound effects for bow string releases, egg cracking/impacts, wooden base hits, and ground collisions.
